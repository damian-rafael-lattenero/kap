Supervisor

class Supervisor(children: List<SupervisorChild>, val strategy: SupervisionStrategy, val restartPolicy: RestartPolicy)

A group of named Kap bodies supervised together (SPEC-5.0 milestone 5.0): when a child fails, the strategy decides whether only that child restarts (SupervisionStrategy.OneForOne) or the whole group does (SupervisionStrategy.AllForOne); the restartPolicy decides the backoff and the restart cap.

A Supervisor is a description: nothing runs until startIn interprets it as a child of the given scope. Each child runs with the terminal-success semantics of Process — a body completing normally finishes that child for good — while a failure is retried up to the policy's cap; exhausting the cap fails the group with SupervisorExhaustedException whose cause is the last failure. The group completes normally exactly when every child has completed normally. stop() and the death of the owning scope are never failures and never trigger a restart.

The restart policy is a value shared by all children: every child has its own attempt counter, but stateful schedules (withMaxDuration) observe the attempts of the whole group. Prefer pure schedules for supervisors.

val group = Supervisor(
    children = listOf(
        Supervisor.child("bus-tailer") { bus.tail() },
        Supervisor.child("memory-worker") { memory.work() },
    ),
    strategy = SupervisionStrategy.OneForOne,
    restartPolicy = RestartPolicy.exponential(base = 1.seconds, maxRestarts = 5),
)

coroutineScope {
    val handle = group.startIn(this)
    awaitShutdownSignal()
    handle.stop()
}

fun startIn(scope: CoroutineScope): SupervisorHandle

Starts every child as a child of scope and returns the group's SupervisorHandle immediately. The group lives exactly as long as the scope allows — cancelling the scope ends it, structured-concurrency style; no child escapes its scope.
