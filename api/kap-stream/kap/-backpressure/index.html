Backpressure

sealed interface Backpressure

A named backpressure policy — the value that answers "what happens to an element the consumer cannot take yet?". Every KapStream stage takes one; the default is Suspend, which is exact (nothing is ever dropped).

StrategyBufferDropsNever drops
Suspendnonenothingevery element, exact order
Buffer(n)n slotsnothing (the producer waits)every element, exact order
Conflate1 slot, keep latestevery superseded elementthe element buffered at completion
DropOldest(n)n slotsthe oldest buffered element on overflowthe most recent element
DropLatest(n)n slotsthe incoming element on overflowthe buffered (older) elements
Latest(n)n slots, keep latesteverything older than the last nthe last n elements

All strategies preserve the upstream order among the elements they keep; none reorders. Elements are never duplicated.

data class Buffer(val capacity: Int = Channel.BUFFERED) : Backpressure

Exact with decoupling: up to capacity elements wait for the consumer, and the producer suspends only when the buffer is full. Nothing is dropped.

data object Conflate : Backpressure

Keeps only the most recent element: while the consumer is busy, every new element replaces the previous one. Same value as Latest(1).

data class DropOldest(val capacity: Int = 1) : Backpressure

A capacity-slot buffer that drops the oldest buffered element when a new one arrives and the buffer is full — the producer never waits, and the freshest data survives.
