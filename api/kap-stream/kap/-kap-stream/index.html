KapStream

class KapStream<out A>

A backpressured stream of values whose stages are Kaps (SPEC-5.0 milestone 5.0). KapStream is a thin, lawful layer over Kotlin flows — it wraps the runtime, never reimplements it — adding the two things flows leave implicit: the backpressure policy is a named value at every stage, and every transformation is a Kap with the error and cancellation semantics of the rest of KAP.

The default backpressure at every stage is Backpressure.Suspend: exact, nothing is ever dropped. Every other policy is explicit and documented for what it drops (Backpressure).

KapStream.emitted(Kap { bus.read() })
    .every(Schedule.spaced(500.milliseconds))
    .filterKap { event -> Kap { !event.isHeartbeat } }
    .mapKap(concurrency = 4, backpressure = Backpressure.Buffer(64)) { event -> Kap { enrich(event) } }
    .drainTo(outbox)

Streams are cold: nothing runs until a sink (collectAsKap, drainTo) or asFlow collects them, and collection lives in the caller's structured scope — cancellation propagates to the source, no stream escapes.

Collects the whole stream into a List as a Kap. The list is complete by construction: whatever the stream did not drop per its named strategies is in it, in order. Terminal: only use it on finite streams (or bounded ones, e.g. via emitted(...).every(Schedule.times(n))).

fun drainTo(channel: SendChannel<A>): Kap<Unit>

Drains the stream into channel as a Kap, suspending on the channel's own capacity — a backpressured sink. Completion of the stream completes the Kap; a closed channel fails it. The channel is not closed by this sink (the caller owns its lifecycle).
