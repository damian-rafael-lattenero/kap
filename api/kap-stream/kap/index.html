sealed interface Backpressure

A named backpressure policy — the value that answers "what happens to an element the consumer cannot take yet?". Every KapStream stage takes one; the default is Suspend, which is exact (nothing is ever dropped).

KapStream
Link copied to clipboard
class KapStream<out A>

A backpressured stream of values whose stages are Kaps (SPEC-5.0 milestone 5.0). KapStream is a thin, lawful layer over Kotlin flows — it wraps the runtime, never reimplements it — adding the two things flows leave implicit: the backpressure policy is a named value at every stage, and every transformation is a Kap with the error and cancellation semantics of the rest of KAP.
