Meter

interface Meter

A tiny multiplatform metrics SPI: counters, timers and gauges addressed by name and tags. It is the seam an integration module (for example kap-micrometer) implements once, so an application never hand-rolls the same counters around every pump, worker or effect.

The contract

  1. Timed operations take the CALL, not a finished duration. time and timeSuspending run the block and measure it; callers never read a clock just to feed a meter. record exists for durations measured elsewhere (a frame the integration already timed).

  2. The names are identities; tags are dimensions. increment, record and gauge receive the metric name verbatim. No implementation may fold tags into the name: the same name is the same metric for every tag combination.

  3. Instrumentation never breaks the measured code. A Meter implementation must not throw. A foreign implementation that can throw is wrapped once with guarded: the failure is caught and handed to the failure reporter — swallowed silently is not allowed — while the block's value and exception pass through untouched.

  4. Timers record exactly once, on success, failure and cancellation alike; a CancellationException is recorded and then rethrown.

  5. Gauges are read at scrape time. gauge registers a supplier; the backing registry reads it whenever a scrape happens, never at registration.

Noop is the strict OFF: no registry, no clock read on the timed paths, no allocation (the block runs bare), exception-transparent.

val meter: Meter = if (metricsEnabled) MicrometerMeter(registry) else Meter.Noop

meter.increment("poller.cycles")
meter.time("brain.request") { brain.ask(prompt) }
meter.gauge("outbox.depth", Tags.of("lane" to "main")) { outbox.depth().toDouble() }

object Noop : Meter

The strict OFF implementation: every tap is a no-op, time and timeSuspending run the block bare (not one clock read), gauges are never registered. A component wired with Noop is byte-for-byte the uninstrumented one.

abstract fun gauge(name: String, tags: Tags = Tags.Empty, supplier: () -> Double)

Registers a gauge name whose value is read from supplier at scrape time. Registration happens once; the supplier is called by the registry on every scrape and must return the current value (never a cached one).
